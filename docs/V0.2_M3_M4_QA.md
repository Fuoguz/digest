## AI 协议与持久化

模型输出 `readingMode, sections, reviewQuestions`。每个模式具有固定 sections：

| 模式 | sections |
| --- | --- |
| general | summary, mainPoints, arguments, framework |
| academic_paper | researchQuestion, method, findings, evidence, limitations, reusableInsights |
| legal_case | facts, legalIssues, rules, arguments, reasoning, holding |
| policy_document | background, targetAudience, objectives, measures, responsibleActors, timeline, implications |

Section 为 `{status, items, missingReason}`；missing 必须为空 items 并说明原因。模型 Claim 为 `{id,text,kind,evidence:[{paragraphIndex,quote}]}`。kind 仅 source_statement / inference / reusable_insight。

运行时校验必填字段、类型、模式、唯一 ID、数组和文本边界；空结果报错。一次 structured request，JSON/schema/空结果失败最多修复一次。引用不匹配不请求模型“修复原文”。

持久化 Claim 转为 `{id,text,kind,evidenceIds}`。ReadingResult 保存 documentId、requestId、sourceRevision、sections、reviewQuestions、coverage、status、时间；EvidenceAnchor 独立保存。Review Questions 本轮只保存。

源快照 SHA-256 包含正文、模式和段落 metadata。提交时在同一 IndexedDB transaction 核对 documentId、sourceRevision 和 active requestId，写 ReadingResult、Anchors、Document 结果指针。取消或旧请求不得提交；失败不覆盖旧成功结果。刷新加载后再次验证 anchors。

## Evidence 规则

paragraphIndex 从 0 开始，UI 段落编号从 1 开始。quote 非空且在对应段落精确出现一次才 matched。重复（含重叠）为 ambiguous，找不到或段落不存在为 invalid，源版本改变为 stale。无 fuzzy match，不修改引用文字。

程序计算段落内和全文 UTF-16 start/end offsets，end 为排他边界，与 String.slice 和 DOM 文本一致；中文、emoji、换行均覆盖。模型提供的 matched、offsets、pageNumber 不可信并忽略。页码仅来自源 metadata。没有 matched 时显示“暂无可靠原文依据”，不提供假按钮；ambiguous 补充“引文重复，无法唯一定位”，invalid 补充“引用未通过原文核对”。Coverage 只计可定位判断，不代表判断正确。
