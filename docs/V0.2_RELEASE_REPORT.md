# Digest v0.2 Core Release Report

发布日期：2026-09-09。分支：codex/digest-v02。M1/M2 checkpoint：3399679；M3/M4 安全 checkpoint：7e57c7c；Core 提交见 Git 中本报告所属提交。

## 交付结果

完成本地 Core 学习闭环：资料导入 → 结构化研读 → 精确原文依据 → 用户选择问题 → 主动回忆/揭示/评级/后续排期 → 用户沉淀知识点 → AI 关系建议 → 人工确认 → 图谱与来源核查。真实模型验收仍待执行，当前不能宣称真实模型语义质量已经通过验收。

信息架构：Landing `/`；Workspace `/app/` 下 Dashboard、Library、Reader、Review、Graph、Search、Settings。桌面保持 Sidebar；Reader 双栏，手机切换原文/AI。复习与图谱来源可返回原任务。

## 数据与 AI

IndexedDB 保存 Document、ReadingResult、EvidenceAnchor、ReviewCard、KnowledgeUnit、Relation、Activity。保留已发布的存储结构与旧数据迁移；本轮不清库。完整 JSON 备份不含 Key，仅恢复到空学习库，重新校验 Evidence。

四种 Reading Mode、Claim 类型区分、诚实 missing、一次请求加最多一次 repair 保留。新增可选 knowledgeLabel 与 review question claimIds，兼容已有结果。Developer Mode 按需配置，不要求无 AI 的阅读用户先配置。

Evidence 使用精确匹配、唯一性、UTF-16 offsets 与来源版本校验。只有程序能设置 matched；invalid/ambiguous 不提供假定位入口，显示“暂无可靠原文依据”。原文版本改变标记 stale。刷新与历史结果来源恢复仍重新核验。

## Review

逐题独立排期，先回忆再揭示；答案可返回原文核查。Again/Hard/Good/Easy 初始 1/3/7/14 日，之后简单延长，Again 重置。事务保存版本、历史、排期和真实活动；阻止重复添加与重复评级。支持暂停/恢复；过期来源不进入有效队列。Dashboard 真实统计今日完成、到期、连续学习与最近资料。

## Knowledge Units 与 Semantic Graph

重要 Claim 可作为候选，用户编辑名称并确认才沉淀。保留原研读、Claim、Evidence，支持搜索、改名与确认后取消沉淀。

关系六种类型，必须有理由；AI 只能 suggested，用户 confirm/reject 后决定入图。D3 展示方向、类型、理由、节点解释及来源；支持文本/标签过滤与键盘入口。允许孤立节点，不按创建顺序/标签自动连边。每次 AI 建议最多处理 40 个当前有效知识点。

## 最终产品审计与修复

- 修复手机图谱缩放后标签过小：按可用宽度布局，详情进入可见位置。

- 导入文档/活动原子保存，失败保留输入，可重试；取消文件解析不会污染下一次导入。

| 流程 | 实际观察 |
|---|---|

## Accessibility

可见 focus、语义按钮/链接、输入 label、原生 dialog、状态消息、跳到内容、Graph 键盘选择与列表入口、reduced-motion；揭示前不把答案暴露在 DOM。不是 WCAG 全面合规认证。

## 真实限制与明确未实现

1. **真实模型验收待执行**；四模式结构与引用稳定性、长文推理、关系质量必须后续用合法配置有限验收，见 V0.2_REAL_MODEL_ACCEPTANCE.md。
2. 数据仅在当前浏览器和 origin；无云同步，需自行备份。恢复仅支持空库，不提供合并。原 PDF 二进制不保存。
3. Developer Key 为浏览器本地开发配置；没有 Production Proxy、账号、权限、配额或支付，尚非面向所有学生的免配置托管服务。
4. PDF 只解析文本层，不做 OCR、复杂双栏顺序重建或 Word/PPT；长文受模型上下文限制。
5. 简单复习算法，无 FSRS、通知、答案编辑；可暂停题目。回忆草稿不持久化。
6. 图谱是小规模本地实现；无千节点性能保证、向量搜索、RAG 或自动真实性判断。
7. 历史研读可核查来源；若再次从历史结果创建资产时当前研读已变，需回到最新 Reader 操作。

本轮到 v0.2 Core 停止，不进入 v0.3。
