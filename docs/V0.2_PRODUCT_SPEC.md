# Digest 当前产品规格：0.2.1 Pilot candidate

更新：2026-09-18。当前源码优先；旧阶段报告保留为历史证据。此版本尚未获得真实模型与公网放行。

## 核心任务

为论述型、案例型、材料密集型课程提供“材料 → Task → 独立作答 → Feedback → Evidence → Revision → 以后再检验”的最小闭环。

- Course：创建/编辑课程，关联已有 Library 资料，查看任务与近期作答。删除课程级联训练记录但不删除原文或旧学习资产。
- Task：自定问题、必要材料、可选评价标准，可编辑/删除。无自动课程生成。
- Attempt：先保存原答案与题目快照；网络或模型失败后可重试。历史首次作答不被修订覆盖。
- Feedback：一句判断、具体优点/缺口、答案片段、经核对的材料引用和修改动作。没有可靠引用时无链接；语义判断与定位验证分开表达。
- Revision：追加保存答案和修改说明；未自动重新评价，明确尚未验证。支持同题独立重答，或返回课程创建新的问题。

## 路径与界面

Dashboard 优先继续任务、课程、最近作答和材料。Library 保留导入与筛选。Reader 保持原文主视角；反馈引用可直接定位到无研读结果的原文，返回恢复反馈条目和修订草稿。主导航为 Dashboard / Library / Review / Course；Graph 在工具区，现有数据和确认关系规则不变。

warm white、ink black、cobalt、amber evidence。无视觉重做或新装饰动效。表单安全文本渲染，支持 1440/1024/768/390 和键盘操作，reduced-motion 保留。

## 旧能力保持

General、Academic Paper、Legal Case、Policy Document 四模式；ReadingResult、EvidenceAnchor、ReviewCard、KnowledgeUnit、Relation、Activity 均兼容。Active Recall 仍为先回忆 → 揭示 → 核查 → Again/Hard/Good/Easy，排期不改；增加课程再检验入口。

TXT、Markdown、文本层 PDF 与粘贴正文导入保留。无 OCR、Word/PPT、复杂 PDF 排版重建或原 PDF 二进制保存。

## 数据、AI 与限制

IndexedDB v2 仅新增四表。Backup v2 支持新训练对象且兼容 v1 导入，仅恢复至空库，失败无部分写入。学习数据本地保存，无云同步。

生产已有受试用码保护的 Serverless Proxy，普通用户无需 API Key；Key 保存在服务端。Developer 模式浏览器自带服务仅供开发。客户端有 deadline、取消、脱敏错误与结构校验。模型未通过真实验收，不承诺反馈正确。

训练每次材料上限 60,000 字符、答案 16,000；不静默截断，不引入向量库。反馈 schema 严格运行时校验，不渲染模型 HTML。精确引用只证明原文存在。

## Activation 与实验

Activation：学生用自己的真实材料独立回答，并据反馈完成有效修正。代码只记录有变化的修订及说明为 candidate，真实学习质量需人工核查。无掌握率、积分或自动判断激活。

下一实验：5 名学生、同一类论述课程，每人一个真实问题与材料。观察首次独立作答、证据核查、修订是否改善，以及数日后新案例的解释质量。真实模型、公网部署和费用保护未验收前不放行无人陪同 Pilot。
