# Digest v0.2 Core 产品规格

状态：Core 已实现；真实模型验收待执行。历史 M3/M4 QA 保留为阶段记录，当前范围以本文与发布报告为准。

## 定位与信息架构

面向高校学生的 AI 研读与复习工作台。核心价值是可追溯、可复习、可关联。

- `/`：品牌与产品介绍，进入工作台。
- `/app/`：真实待复习、今日完成、连续学习、最近资料。
- `/app/library`：资料列表、正文搜索、标签/类型/模式、收藏、待复习筛选与导入。
- `/app/reader/:documentId`：原文、结构化研读、Evidence、加入复习、沉淀知识点。
- `/app/review`：逐题回忆、揭示、核查、评级、管理暂停状态。
- `/app/graph`：确认知识点、关系建议与确认、语义图谱、来源。
- `/app/search`：跨资料、知识点、复习题搜索。
- `/app/settings`：本地备份/恢复与按需 Developer AI 配置。

## 导入与 Library

支持粘贴、拖放 TXT、Markdown、文本层 PDF；保存文件名、正文、段落与可靠页码。不保存原 PDF 二进制，不做 OCR 或复杂排版重建。扫描件显示“当前 PDF 未检测到可提取文本，请使用文本版 PDF 或粘贴正文。”无 AI 配置也可导入、阅读与管理。

首次启动尽可能迁移旧 Demo 的标题、insight、标签、日期。自动 JSON 备份、保留旧 key、缺原文标记 legacy_incomplete；不补造原文、Evidence 或题目。失败后下次启动可重试。

## Reader 与 AI

Desktop：Sidebar + 原文约 55% + AI 约 45%；768/390 使用原文/AI 标签切换。引用点击精确高亮 amber 原文；手机提供返回 AI 判断。来源链接可返回复习或图谱任务。

四种模式：

| 模式 | Sections |
|---|---|
| general | summary, mainPoints, arguments, framework |
| academic_paper | researchQuestion, method, findings, evidence, limitations, reusableInsights |
| legal_case | facts, legalIssues, rules, arguments, reasoning, holding |
| policy_document | background, targetAudience, objectives, measures, responsibleActors, timeline, implications |

每节包含 status、items、missingReason；Claim 含 id、text、kind、evidenceIds，可选 knowledgeLabel。kind 明确区分资料陈述、AI 推论、可复用洞见。材料不足允许 missing。模型引用仅提议 paragraphIndex/quote，程序决定是否 matched。

单次结构化请求，运行时校验，最多一次受控修复；可取消。失败、超时、结构错误保留旧成功结果。保存检查资料 ID、版本与请求 ID。Evidence coverage 仅表示可定位，不表示判断正确。

## Active Recall

用户明确选择问题加入复习；问题保存独立状态和来源。Question → 自行回忆 → Reveal → 来源核查 → Again/Hard/Good/Easy。揭示前不渲染答案；回忆草稿不持久化。

初始间隔 1/3/7/14 日；后续 Hard/Good/Easy 按前次间隔延长，Again 重置一天。事务保存评级、版本、历史及活动。重复添加同资料同题会复用已有题；重复评级被版本检查拦截。可暂停、恢复。到期时间到达后重新进入队列。原文变化的卡片退出有效队列并提示检查。

Dashboard 指标来自实际活动与卡片，无积分、掌握率、虚假游戏等级。

## Knowledge Units 与 Semantic Graph

Reader 从重要 Claims 建议最多 8 个知识点候选；模型可提供简短名称，否则用判断摘要作为候选。用户编辑并“沉淀为知识点”才正式保存；不保证每份短材料都产生 3 个知识点。

知识点关联 Document、Reading Result、Claim、Evidence，支持改名、取消沉淀、搜索和来源核查。取消沉淀需确认，并删除相连关系。

关系支持 related_to、supports、contradicts、example_of、prerequisite_of、causes。AI 必须提供类型与理由，允许空数组；建议以 suggested 保存，用户确认后进入正式图谱，拒绝建议不反复自动加入。不按标签、时间或 group 连边。

D3 显示确认节点、方向、关系类型；点击与键盘操作查看解释/理由/来源；搜索或标签过滤。无关知识可以孤立。关系确认是用户判断，不等价于学术事实认证。

## 视觉、恢复与边界

warm white、ink、cobalt，amber Evidence。轻量分隔与排版，Reader 为视觉主体；Review 聚焦一道题；图谱优先可解释性。支持 1440/1024/768/390、可见键盘焦点、语义按钮、文本状态、reduced-motion。

完整 JSON 备份不含 API Key；仅允许恢复到空学习库，避免覆盖已有资料。清理浏览器仍可能丢失本地数据。Developer Mode 浏览器直连仅供当前 Core，普通用户生产分发仍需后续独立 Proxy 工作。

本轮不含账号、支付、云同步、OCR、Word/PPT、FSRS、向量数据库、RAG、多用户和企业迁移框架。
