## Method

10 个固定案例：4 Reading + 6 Feedback；每个一次真实模型请求，没有触发 Reading 结构修复；另有 2 次真实 UI Feedback。全部经过公开 Preview 同源 API、正常试用码和签名会话，不直接调用模型供应商。没有读取/暴露 API Key。

素材：[网信办正式第二、三条原文](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)、[Attention Is All You Need 摘要原句](https://arxiv.org/abs/1706.03762)，以及明确标注的教学虚构案例/边界材料。英文仅 25 词句段，法律教学例不是实际判决，F6 是重复讨论段落组成的加长材料；不冒称完整论文或真实学生研究。

运行：node tests/browser/real-model.mjs。案例与期望冻结于 tests/fixtures/real-model-cases.mjs；逐次机器结果在忽略目录 qa-artifacts/real-model/results.json。人工语义审阅由执行本轮的 Codex 逐条对照材料、答案与反馈完成，未由独立教师盲审。

Layer 1：schema、答案片段、quote、paragraph、offset、sourceRevision 由现有程序验证。Layer 2：人工检查引文是否支持判断，用户是否真说过被批评的观点，修改建议是否有帮助。82 个候选引文全部匹配仅是本批样本的定位结果，不是模型准确率。

初次 runner 忘传 Reading requestId，4 个 Reading 输出内 anchor ID 使用 undefined-e-* 前缀；这是独立验收 harness 的命名问题，各案例隔离、未写产品库，不影响引用文本/段落/offset 的校验或人工语义结论。已补传 requestId，未为改名重发收费请求。真实 UI 通过产品仓储生成正确 ID。

结果是 6 PASS、4 PARTIAL、0 FAIL。PARTIAL 均为本表列明的非阻塞表达/审慎性限制，不合成为“准确率”。10 次请求耗时约 19.9–57.7 秒；这不是延迟服务保证。

## Public UI and adversarial separation

1440 和 390 两次真实反馈均指出“大学在境内”不等于“向境内公众提供服务”，真实原文链接、返回、修订、刷新、新开页面通过。原答和修订同时存在，没有提前展示参考答案。

错误 quote、缺字段、malformed、空文本、429/500/503/504、network、取消、版本变化和请求竞争通过自动测试/明确标记的浏览器故障注入覆盖。本批真实模型恰未返回这些坏输出；不将注入输出记为真实模型结果。未重新进行真实关系建议质量 benchmark；Graph 非本轮核心路径，旧 confirmed relation 安全测试保留。

## Decision and limits

**READY WITH KNOWN NON-BLOCKING LIMITATIONS**，限 5 名受邀学生、精选短材料的探索性学习试用，不作为教师评分工具或法律结论服务。未发现当前闭环阻塞；没有以新增能力掩盖问题。

下一步停止功能开发，收集学生是否实际读懂反馈、证据是否减少误导、修订是否改善解释的证据。对内部字段名、重复 gap 与过细批评保留样例观察；出现会改变结论的错误反馈时暂停扩展试用并修复。现有素材规模不覆盖完整长论文、复杂判决或整课程文库。
