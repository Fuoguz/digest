## M3 — Reader 与四种 Reading Modes

左原文/右研读；General、Academic Paper、Legal Case、Policy Document schema 与展示。

## M4 — Evidence Anchors

Claim → 查看依据 → 暖黄色定位高亮；无可靠依据诚实提示；Completeness/Grounding Check。

## M5 — Active Recall

逐题 Question → Recall → Reveal → Again/Hard/Good/Easy 与 simple-v1 调度。

Claims 建议 3–8 个 KnowledgeUnit，经用户沉淀；Relation suggested→confirmed；D3 显示 type/reason，节点回 Reader/Evidence，无关知识不连边。

## M7 — Visual polish / responsive / states

完成 1440/1280/1024/768/390，重点打磨 Reader、键盘、reduced-motion、empty/loading/error。

## M8 — Tests / legacy cleanup / docs

补齐 migration、review、reading schema、relation、evidence、API failure 测试；新链路通过后删除根 app.js 和被替代模块；更新 README/PRODUCT_EXPLANATION。

## 延期

## M1+M2 验收

1. `/` 与 `/app` 分离，深链可刷新。
2. 文本、TXT、Markdown、文本层 PDF 可入库且重载不丢。
3. 无文本 PDF 显示批准文案，不创建空记录。
4. Library 可搜索、筛选、收藏；Dashboard 使用真实数据。
5. 旧 key 保留，迁移不伪造原文/Evidence/题目；失败可重试并可下载备份。
6. npm test/build 通过；1440/390 无横向溢出和关键操作遮挡。
7. 完成后 STOP，不继续 M3。
