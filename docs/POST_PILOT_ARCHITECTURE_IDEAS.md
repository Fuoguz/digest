# Post-Pilot architecture ideas

研究笔记，2026-09-22。不是开发计划。先观察 5 位学生完成独立作答、核查与修订；下列候选本轮均未实现。

| Candidate | Why / 用户问题 | 什么 Pilot 证据支持建设 | 什么证据意味着不建 |
|---|---|---|---|
| SourceBlock | 稳定定位段落、页码与版本，减少返回材料迷路 | 多位学生因跨页、图表或来源版本无法核查关键反馈 | 当前段落定位足够，失败来自反馈内容而非定位 |
| SourceClaim | 保存命题及条件/例外，降低关键内容遗漏 | 多份材料反复漏掉同一种决定性条件，简单提示修正仍无效 | 无重复遗漏模式，人工清单或任务 rubric 已足够 |
| Coverage State | 区分输入完整与已覆盖关键内容 | 学生反复把摘要当完整复习范围并因此答错 | 学生能够理解摘要限制，覆盖标记没有改变学习行为 |
| Material / Model Boundary | 让外部补充和材料判断清楚分开 | 多人被无来源补充误导，现有支持提示不足 | 现有提示和 Evidence 已能让学生正确核查 |
| Misconception | 保留跨 Attempt 重复的具体误解 | 同一学生跨任务重复相同混淆，历史回看成本明显 | 错误主要是单次笔误或任务不清，没有稳定模式 |
| Transfer Task | 检验修订后是否能在新情境应用 | 原题修订正确，但人工新题仍失败，学生愿意继续练习 | 首次反馈尚不可信，或学生没有再次练习需求 |
| Incremental Re-analysis | 更新材料后仅重核受影响反馈 | 长材料频繁更新，重新分析费用/等待成为实际阻塞 | 材料基本不变，重新执行低成本且少发生 |
| Course Intelligence Pack | 汇总课程范围、rubric 和可核查资料 | 多任务重复配置同一范围耗时，学生请求可复用上下文 | 课程内任务差异大，现有 Course/Task 足够 |
| Learning Relation Graph | 解释概念关系如何导致某种错误 | 真实误解跨多个概念，关系视图比文本解释更易修正 | 学生主要沿任务和材料继续学习，图谱没有帮助答对 |

候选均需比小改动或清楚文案更有效才值得实施；不以参考仓库有此对象为建设理由。来源与阅读边界见 [PILOT_REFERENCE_NOTES.md](PILOT_REFERENCE_NOTES.md)。
